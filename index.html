Business Engine

A private automation app for one independent YouTube channel.

Business Engine is a small, privately run program that helps produce original videos for its owner's own YouTube channel. It uses the official YouTube Data API to upload those videos and the YouTube Analytics API to read that channel's own statistics, so it can learn which videos are useful to viewers.

It is not a public service: nobody else signs in to it, and it does not access anyone else's account or data.
